📐 从影子反推地理位置

--
太阳高度角
--
影长/物高比
--
估算纬度
💡 用法：照片中找已知高度的物体→量影子相对长度。
• 影子比 <1 → 太阳较高 → 中午或低纬度 | 影子比 >2 → 太阳低 → 早晚或高纬度
• 影子方向 +180° = 太阳方向 → 结合日期/时间可反推可能纬度（核心定位方法）
• 如果有多张不同时间的照片+影子 → 交叉定位可大幅缩小范围

🧭 地磁偏角 — 指南针 vs 真北

--
磁偏角 Declination
--
总磁场强度 (nT)
--
磁倾角 Inclination
💡 OSINT 用途：照片里的指南针/手机罗盘读数=磁北，地图用真北。
磁偏角为正(+)=磁北在真北以东→真北=罗盘读数−偏角
磁偏角为负(−)=磁北在真北以西→真北=罗盘读数+偏角
磁偏角随地点变化很大（−30°~+30°），可用于缩小位置范围。
精度约 ±2°（全球网格查表 + NOAA 数据源）

⭐ 北极星高度 = 观测者纬度

北极星在地平线上的角度 ≈ 你所在的北纬度数。北极星 40° 高 → 北纬 ~40°。仅北半球有效。

🌌 易识别星座

北半球：北斗七星(大熊)、猎户座(冬)、仙后座(W)、天鹅座(夏季大三角)
南半球：南十字座、半人马座

🕐 星空时钟

同一颗星每天早~4分钟升起。星空每周向西偏~28°。知道某颗亮星的高度和方向→可反推时间和纬度。

🪐 行星可见性

金星：日落后/日出前最亮"星"，永不超过日出前3h/日落后3h
木星：全年大部分可见，很亮
火星：红色，约每26个月冲日最亮
土星：淡黄色，比木星暗

📷 照片星轨

• 星轨是同心圆弧→圆心=天极

• 南半球：无亮极星

📋 网络谜踪 系统化分析流程

拿到一张需要定位的照片后，按以下顺序逐项排查：

  1. 1. 拍照时间 — EXIF / 截图时间 / 社交媒体时间戳 → 确定日期和大致时间（注意时区）
  2. 2. 太阳/影子 — 影子长度→太阳高度角；影子方向→太阳方位角 → 使用「阴影反推」工具估算纬度
  3. 3. 月亮 — 照片中有月亮→月相+照度约束日期；月亮高度+方向辅助定位
  4. 4. 文字系统 — 招牌/广告/路标上的文字 → 确定语言/国家/地区
  5. 5. 车牌格式 — 颜色+排列 → 确定国家（有时精确到省/州）
  6. 6. 道路行驶方向 — 靠左/靠右 → 排除一半国家
  7. 7. 路标样式 — 颜色+形状+字体 → 国家识别（高速路牌颜色特别有用）
  8. 8. 路桩/护栏 — 不同国家的路桩（Bollard）设计差异极大
  9. 9. 建筑风格 — 屋顶/窗户/阳台/材料 → 区域识别
  10. 10. 植被类型 — 热带/温带/地中海/针叶林 → 气候带→纬度范围
  11. 11. 电线杆/路灯 — 样式差异 → 国家/地区识别
  12. 12. 邮筒/消防栓 — 颜色+形状 → 国家特定
  13. 13. 出租车颜色 — 许多城市有统一的出租车涂装
  14. 14. 货币/价格标签 — ¥/$/€/£ 符号 + 价格水平 → 区域判断
  15. 15. 电源插座 — 室内照片中的插座样式 → 国家集团识别
  16. 16. 星空 — 北极星高度=纬度；星座可见性→季节+半球
  17. 17. 旗帜 — 国旗/省旗/市旗 → 直接定位
  18. 18. 数字格式 — 阿拉伯数字 vs 东方阿拉伯数字 vs 中文数字 → 文化区域
  19. 19. 电话区号 — 广告上的电话号码 → 国家代码
  20. 20. 交叉验证 — 把以上所有线索综合，在 Google Maps/Street View 中验证

🌐 WGS84 (GPS)

最通用的坐标系。谷歌地图、GPS 设备、OpenStreetMap 均使用。经纬度用十进制度或度分秒表示。
EPSG:4326

🗺️ UTM (通用横墨卡托)

将地球分为 60 个 6° 宽的纵带（1~60），和 20 个 8° 高的横带（C~X，不含 I、O）。
坐标用 带号 + 东距 + 北距（米）表示。
例：北京 ≈ 50S 439000E 4418000N
军用/地形图常用

🎯 MGRS (军用网格)

UTM 的军用变体，用 网格区 + 100km 方格 + 数字坐标。
例：白宫 ≈ 18S UJ 2306 0721
精度由数字位数决定：4位=1km，6位=100m，8位=10m，10位=1m。
北约标准

📱 Plus Codes (Open Location Code)

Google 推出的短码定位系统，用字母+数字编码经纬度。
例：北京天安门 ≈ 8PFRW6XW+2V
短码（6~7位）≈ 城镇级别；长码（10位+）≈ 建筑级别。
不依赖 GPS 亦可使用

🔤 What3Words

把地球分为 3m×3m 的方格，每格用 3 个英文单词表示。
例：白金汉宫 = ///fees.sulk.hooks
优点：易记、语音友好；缺点：封闭商业系统、不同语言不互通。
商业/非开源

📐 Geohash

用 Base32 字母将经纬度编码为一维字符串。越长越精确。
例：北京 ≈ wx4g0bm
特点：前缀相同的点位置相近，适合空间索引。
数据库/后端常用

🌍 投影与失真

• 墨卡托 (Web Mercator)：谷歌/OSM 使用 → 高纬度地区面积严重放大（格陵兰看起来像非洲大）
• 等距圆柱投影：经纬度直接变 xy → 形状在高纬度压扁
• 看卫星图时注意：非正上方拍摄会有倾斜失真

📏 精度参考

• 1° 纬度 ≈ 111.32 km（恒定）
• 1° 经度 ≈ 111.32 × cos(纬度) km
• 0.001° ≈ 111m
• 0.00001° ≈ 1.1m
• DMS 1″ ≈ 30m（纬度）
• 4 位 MGRS ≈ 1km；10 位 ≈ 1m

✈️ 凝结尾 (Contrail)

高空飞机会产生凝结尾（白色尾迹）。
• 持续时间长→高空湿度大→可能变天
• 多条平行尾迹→可能是繁忙航线
• 尾迹方向+太阳位置→可估算飞行方向

🛬 进近灯光

机场进近灯光系统在夜间非常醒目：
• 白色频闪灯顺序闪烁→指向跑道
• 看到进近灯→附近 5km 内有大型机场
• 不同机场的灯光配置有差异
