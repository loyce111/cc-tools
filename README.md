# CC的妙妙工具 — 网络谜踪 OSINT Toolkit

🔍 一站式网络谜踪（Internet Sleuthing）地理定位工具合集。

## ✨ 功能模块

| 模块 | 功能 |
|------|------|
| ☀️🌙 日月位置 | 太阳+月亮高度角/方位角/赤纬/月相 |
| 🕐 地方时 | 日出日落/晨昏蒙影/黄金蓝调时刻 |
| 📍 坐标工具 | DMS↔十进制互转/Haversine距离 |
| 📐 阴影反推 | 影子→太阳高度→可能纬度 |
| 🧭 地磁偏角 | 指南针偏差查询 |
| ⭐ 星空参考 | 25颗亮星/星座识别/行星可见性 |
| 🌍 地理工具 | 对跖点/时区估算/地图链接生成 |
| 📖 知识图鉴 | 15类知识卡片(路桩/车牌/文字/出租车…) |
| 📋 线索清单 | 20步系统化OSINT分析流程 |
| 🗺️ 坐标系统 | UTM/MGRS/Plus Codes/Geohash参考 |
| ✈️🚄 交通查询 | 航班+高铁时间估算/机场代码速查 |
| 📷 照片分析 | EXIF解析/GPS定位/影子测量 |

## 🚀 使用方式

### 浏览器直接打开
双击 `osint-toolkit.html` 即可，纯前端无需服务器。

### 安装为 App (PWA)
- **桌面端**：Chrome/Edge → 地址栏安装按钮
- **手机端**：浏览器 → 添加到主屏幕
- 离线也能使用！

## 🔧 技术

- 纯 HTML/CSS/JavaScript，零依赖
- NOAA 太阳位置算法 (~0.01° 精度)
- 月亮位置简化星历
- WMM2025 地磁模型
- JPEG EXIF 解析器
